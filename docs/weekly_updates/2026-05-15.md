## Two reframings worth flagging

1. **"Prong 1 is scaffolding; the product is Prong 2 + Prong 3."** Captured in [`docs/RESEARCH_ARC.md`](https://github.com/danparshall/lobby_analysis/blob/main/docs/RESEARCH_ARC.md). Prong 1 (statute → typed-cell SMR) earns its keep two ways: it makes Prong 2 (portal extraction) cheaper by giving every per-state portal pipeline a shared schema instead of 50 bespoke extractors, and it produces the legal-vs-actual gap (what the statute *requires* vs. what the portal *exposes*) as an additional research artifact. This framing has been the implicit working model for ~3 weeks; this week it became the explicit working model so successor-branch agents stop relitigating it.

2. **"Per-rubric projection is gradient signal, not deliverable."** The eight Phase C projection functions aren't outputs in their own right — they're the indirect ground truth that closes a **Ralph loop** on Prong 1's prompt iteration. Two error signals feed the same optimizer: cross-rubric projection-distance (Phase C) catches *absolute*-accuracy errors; within-state across-vintage stability (Track A — same prompt against OH 2007 / 2010 / 2015 / 2025) catches *consistency* errors. **Noise floor measurement is explicitly named as gating** before the optimizer runs — run N independent extractions on a fixed prompt, compute `σ_noise` on `loss`, require every iteration thereafter to clear >2σ_noise to count as a real improvement. Without that baseline the loop chases 1σ flukes. Three risks flagged up front: implicit weighting in `Σ |diff|` (FOCAL-58 weights heavier than Sunlight-13); Goodhart (prompt tweaks that minimize projection-distance push toward cells that *project well*, not cells that *are correct* — Track A is the only signal that doesn't go through a rubric, so treat it as co-equal); cost asymmetry (single-state Ralph ≈ $4/iteration, 50-state ≈ $150/iteration, so the $50–500/month LLM budget caps full-scale iteration at 2–3 runs/month — pilot first).
