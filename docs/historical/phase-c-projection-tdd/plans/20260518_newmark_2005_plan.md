# Newmark 2005 Projection Implementation Plan

**Goal:** Ship `project_newmark_2005(state, panel, cells)` — a per-state per-panel projection function that reads 14 v2 compendium row families (all pre-existing; **zero new rows**) and produces Newmark 2005's per-panel partial score, validated against Table 1's per-state per-panel `index.total` via weak inequality across the 6 published panels (1990–91, 1994–95, 1996–97, 2000–01, 2002, 2003).

**Originating conversation:** [`../convos/20260518_newmark_plans_drafting.md`](../convos/20260518_newmark_plans_drafting.md) (Sub-2 of Phase C — Stream 2 plans: Newmark 2017 + Newmark 2005). Builds directly on the Sub-0 playbook gap audit ([`../results/20260514_playbook_gap_audit.md`](../results/20260514_playbook_gap_audit.md)). Pairs with [`20260518_newmark_2017_plan.md`](20260518_newmark_2017_plan.md) — same session, must land first.

**Context:** Rubric #5 in Phase C's locked rubric order. Newmark 2005 is the **explicit predecessor of Newmark 2017** (and successor of Opheim 1991 — paper line 117: "Similar to Opheim's (1991) measure"). Its Phase C role is **temporal-coverage validation**: the 6 panels span 1990–2003, providing the project's only multi-vintage ground truth in the contributing-rubric set on BoS-derived disclosure observables. Newmark 2005 reuses 14 of 14 compendium rows — **zero new rows introduced**. The validation utility is structurally weaker than Newmark 2017's (Newmark 2005 publishes per-state TOTALS only — no sub-aggregate breakdown), but the temporal panel depth uniquely positions Newmark 2005 in the contributing-set.

**Confidence:** High on per-item mappings (spec doc factually-audited 2026-05-13; **100% reuse** verified by Phase 0 cross-check: all 14 rows present in v2, plus the 8 cadence cells needed for the new frequency item). High on data year (paper-explicit, 6 panels). **Low on direct validation utility** — weak inequality `our_partial ≤ paper_total` is the only available Phase C check (Newmark 2005 publishes per-state totals only; no sub-aggregates, no per-item).

**Architecture:** Declarative `_ATOMIC_SPEC` table dispatcher mirroring `pri_2010.py` + `newmark_2017.py`. 11 of 14 items are pure binary-cell → 0/1 passthroughs; 3 typed-cell `IS NOT NULL` reads (reused via import from `newmark_2017` module); 1 actor-agnostic OR (gifts; **imported from `newmark_2017`**); 1 NEW 8-cell cadence-OR helper (`project_cadence_more_than_annual_or`, introduced here, rubric-agnostic by design). **No `index.total` aggregation function** — projection cannot reproduce Newmark 2005's 0–18 published total (4 prohib + 1 penalty OOS). **No sub-aggregate APIs** — Newmark 2005 doesn't publish sub-aggregates, so exposing `def_section_total_partial` / `disclosure_section_total_partial` would smuggle a wrong-by-design API even though the underlying integers are computable.

**Branch:** `phase-c-projection-tdd` (worktree at `.worktrees/phase-c-projection-tdd`).

**Tech Stack:** Python 3.12, Pydantic v2, pytest, `uv` for env management. `load_v2_compendium()` from `lobby_analysis.compendium_loader` for cell access. `STATE_NAME_TO_USPS` from `scoring.calibration`. **Imports from `lobby_analysis.projections.newmark_2017`:** `project_gifts_actor_agnostic_or`, threshold-IS-NOT-NULL helpers (or the dispatcher pattern they share).

## Validation regime — Weak-inequality only

**Tier:** Weak-inequality only (per Sub-0 gap audit Pattern 2 third tier; same regime as Opheim 1991).

**Ground truth:** Newmark 2005 paper Table 1 (paper lines 182–686). Per-state per-panel `index.total` for 50 states × 6 panels = 300 cells, plus a `2003_total_plus_penalty` 7th column (47 cells; CO/TN/WV missing in 2003 per endnote 8 — penalty composite not extractable for those three states).

- **300 cells usable for the main weak-inequality check** (`our_projected_partial ≤ paper_index_total[state][panel]` for all 50 × 6 panels).
- **0 cells usable for sub-aggregate tolerance check** (paper publishes only totals, not sub-aggregates).
- **0 cells usable for per-atomic-item check** (paper publishes only totals).
- **47 informational cells** for the 2003 total-plus-penalty column (NOT used in validation; penalty is OOS).

**Sample:** All 50 states are scored in all 6 panels of Table 1 (Newmark 2005, unlike Opheim, doesn't have missing-state caveats on the main index — the missing-data flag is only for the 2003 penalty composite).

**Available Phase C checks:**

- `project(cells, panel)["total_partial"] <= reference[state][panel]` for all 50 × 6 = 300 panel-state combinations. The 4 OOS prohib items contribute `∈ [0, 4]` to `paper_total`; the inequality must hold by ≥0 margin.
- **Cross-rubric audit is the actual quality check.** Newmark 2005's BoS-sourced atomic items are correct-by-construction when our compendium extraction is validated against (a) Newmark 2017 sub-aggregates on the 2015 vintage where rows overlap, (b) PRI 2010 per-item data on the 2009-10 vintage where rows overlap. The temporal-vintage drift Newmark 2005 measures (1990–91 vs 2003 correlation = 0.46 per paper line 158) is itself a Phase 4 audit input: rows that drift across panels in our extraction should align with the panel-level drift Newmark observed.

**Validation tolerance:** `<=`. No equality check available.

**Plan-honesty note (do NOT promise what the regime can't deliver):** Tests **must not** assert `abs(our_partial - paper_total) <= N` or any equality-flavored tolerance. Only `<=` may be asserted on the partial-vs-total relationship. The 4-OOS-prohib gap explicitly opens a `[0, 4]` headroom.

**No sub-aggregate API.** Even though `def_section_total_partial` + `freq_section_total_partial` + `disclosure_section_total_partial` are computable from the projected per-item values, **the module must not expose them as validation outputs** — Newmark 2005 doesn't publish these sub-aggregates, so a public API would imply a reproducibility we don't have. Sub-aggregates may be exposed as **informational fields** on the score model (helpful for debugging / Phase 4 audit) but tests do NOT assert equality against any published value.

**Note on Opheim cut vs Newmark cut** (Sub-0 gap audit Pattern 4 — same-row-different-binary-cut):

- **Newmark 2005**: 8-cell OR (any sub-annual cadence) → 1.
- **Opheim 1991**: 2-cell OR (monthly only) → 1.
- Same underlying row family; different binary cuts. A state with quarterly-only reporting: Newmark 2005 = 1; Opheim = 0. **Both projections are correct for their respective rubric's published rule.** This is the canonical example of Pattern 4 — document explicitly in the helper docstring.

**Note on registration-vs-reporting cadence** (paper line 124–127):

- Newmark's source quote bundles registration cadence and reporting cadence into a single binary.
- **Projection convention:** read *reporting* cadence (PRI E1h/E2h rows, i.e., the cadence cells listed above), NOT registration cadence (CPI #199 `lobbyist_registration_renewal_cadence` row — distinct row family).
- Rationale: Newmark's broader category is "frequency of reporting requirements"; "reporting" framing dominates. CPI #199 is a distinct row family (renewal cadence vs reporting cadence) per the CPI mapping. If a state has annual reporting but more-frequent renewal, Newmark codes 0 (no quarterly reporting), which matches the projection convention.

**Note on "annual" vs "other"** — paper line 125–127: "more frequently than once per year ... 0 for those states reporting once per year or less." The "annual" cadence cell is NOT read by Newmark 2005's helper (annual = not-more-frequent-than-annual). "Other" cadence cell is also NOT read (semantic ambiguous; safer to exclude than to misclassify). **Helper reads only the 8 explicitly sub-annual cells.**
