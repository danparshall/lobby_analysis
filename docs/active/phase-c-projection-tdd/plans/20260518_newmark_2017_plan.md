## Validation regime — Medium (per-state sub-aggregate)

**Tier:** Medium — per-state sub-aggregate ground truth published (Newmark Table 2). Per-atomic-item per-state ground truth is **not** published; per-item validation comes via cross-rubric overlap (Phase 4).

**Ground truth:** Newmark 2017 Table 2. Per-state values for 4 columns: `def.section_total`, `prohib.section_total`, `disclosure.section_total`, `index.total`. 50 states × 4 columns = 200 cells. **Of these, 100 are Phase C validation-usable** (`def.section_total` and `disclosure.section_total`); the other 2 columns are informational (`prohib.section_total` OOS by scope; `index.total` derivable but not directly checkable since `prohib.section_total` not projectable).

**Available Phase C checks:**

The 50-state sub-aggregate check is a **future-validation harness**, not landing-time evidence. Of the 14 in-scope items, **6 read NEW v2 rows** (4 in the def battery: `def_actor_class_elected_officials`, `def_actor_class_public_employees`, `lobbyist_registration_threshold_expenditure_dollars`, `lobbyist_registration_threshold_time_percent`; 2 in the disclosure battery: `lobbyist_spending_report_includes_total_expenditures`, `lobbyist_or_principal_spending_report_includes_contributions_received_for_lobbying`). No upstream rubric's published per-state data populates these 6 rows. **At landing time, every state `xfail`s** on def.section_total (4 NEW rows in the battery) and on disclosure.section_total (2 NEW rows). The test parameterization is committed so that when Phase D extraction lands, XFAIL → XPASS flips and signals "remove the marker, this validates now".

- `project(cells)["def.section_total_partial"] == reference[state]["def.section_total"]` for all 50 states — **all `xfail` at landing**, pending Phase D. Tolerance once cells are populated: `==` (unweighted integer sums of binary atomic items, no rounding).
- `project(cells)["disclosure.section_total_partial"] == reference[state]["disclosure.section_total"]` for all 50 states — **all `xfail` at landing**, pending Phase D. Same shape, same tolerance.
- Number of validation cells once Phase D lands: **100** (50 states × 2 sub-aggregates). At landing time of this plan: **0** actually-checking cells, 100 committed-as-`xfail`.

**Landing-time evidence (what actually validates the projection when this plan ships):**

1. **Per-item helper tests** — every helper's input/output contract tested against synthetic cells with truth-table coverage. This is the only direct check on projection correctness at landing.
2. **Ground-truth loader self-consistency** — `def + prohib + disclosure == index.total` for all 50 rows of the Phase 0-extracted Table 2; sub-aggregate value-range bounds; paper-documented distribution sanity (≥1 state at disclosure.section_total = 7 per Newmark's abstract — ideally ≥15).
3. **Cross-rubric overlap on the 8 OLD rows** — the 8 of 14 v2 rows already populated by CPI 2015 / Sunlight 2015 / PRI 2010 give a partial cross-rubric agreement check at the per-item layer. Not the full def.section_total / disclosure.section_total (those need all 7 inputs each), but signal that the OLD-row projections agree with prior rubrics' readings on the shared rows. Phase 4 prototype seed.

**Validation tolerance:** `==` exact match. Integer sums, no rounding.

**No per-atomic-item validation against Newmark directly.** Cross-rubric overlap (Phase 4) is the per-item check — primarily against PRI 2010 (which DOES publish per-item per-state data) on rows both modules read. **Note on vintage:** PRI 2010 is 2009–10 statute vintage and Newmark 2017 is 2015 — for cross-rubric per-item checks on PRI-readable rows, expect vintage drift on any row where state law changed in those years. Use CPI 2015 + Sunlight 2015 (both 2015-vintage) as the primary same-vintage cross-rubric checks; treat PRI 2010 overlaps as informational.

**No end-to-end aggregation check.** `index.total` would require `prohib.section_total` (OOS); plan asserts **the module must not** expose `project_newmark_2017_index_total` — would smuggle a wrong-by-design API.

## Module structure (mirror PRI 2010 — declarative table dispatcher)

Module path: `src/lobby_analysis/projections/newmark_2017.py`.

**Module docstring shape** (copy from `pri_2010.py`):

- Module purpose (1 paragraph): rubric vintage (2015 BoS), projection scope (5 prohib OOS), validation regime (medium / per-state sub-aggregate).
- Spec doc path.
- Ground-truth source: Newmark 2017 paper Table 2 (50 states × 4 columns; def.section_total + disclosure.section_total are validation-usable). **No CSV exists** — Phase 0 task extracts Table 2 to a generated CSV in `papers/`.
- Rename mapping table (7 renames documented above).
- Conventions: declarative `_ATOMIC_SPEC` table; `project_gifts_actor_agnostic_or` helper (rubric-agnostic by design); `unable_to_evaluate` convention for missing cells.

**Constants:**

```python
OOS_ITEMS: frozenset[str]                     # 5 prohib.* (disclosure-only Phase B)
IN_SCOPE_ITEMS: tuple[str, ...]               # 14 items in fixed order (def first, then disclosure)
DEF_SECTION_ITEMS: tuple[str, ...]            # 7 def.* items
DISCLOSURE_SECTION_ITEMS: tuple[str, ...]     # 7 disclosure.* items
LEGAL_AXIS: Final[str] = "legal_availability"
UNABLE_TO_EVALUATE: Final[Literal["unable_to_evaluate"]] = "unable_to_evaluate"
```

**Declarative spec table** (mirror PRI's `_ATOMIC_SPEC` dict):

```python
# {newmark_2017_item_id: SpecEntry}
# SpecEntry is one of:
#   ("binary_true", row_id, axis)               — 11 items (4 def + 7 disclosure, including the
#                                                  contributions-received item which is a single read
#                                                  on the `_lobbyist_or_principal_` row)
#   ("typed_is_not_null", row_id, axis)         — 3 def.*_standard threshold cells
#   ("gifts_actor_agnostic_or", None, None)     — dispatched to named helper (1 item)
```

**Named helper:**

```python
def project_gifts_actor_agnostic_or(cells: dict) -> int | Literal["unable_to_evaluate"]:
    """OR over the two actor-side gifts/entertainment/transport/lodging rows.

    Reads `lobbyist_spending_report_includes_gifts_entertainment_transport_lodging`
    AND `principal_spending_report_includes_gifts_entertainment_transport_lodging`
    on `legal_availability` axis. Returns 1 if either is TRUE, 0 if both FALSE,
    `unable_to_evaluate` if either cell missing.

    Rubric-agnostic by design. Newmark 2005 + Opheim 1991 import this helper.
    """
```

**Pydantic score model:**

```python
class Newmark2017Score(BaseModel):
    model_config = ConfigDict(frozen=True)
    state: str                                  # USPS code
    per_item_scores: dict[str, int | str]       # 14 items → 0/1 or "unable_to_evaluate"
    def_section_total_partial: int              # sum over DEF_SECTION_ITEMS, ∈ [0, 7]
    disclosure_section_total_partial: int       # sum over DISCLOSURE_SECTION_ITEMS, ∈ [0, 7]
    # NO index.total (cannot reproduce; prohib OOS).
    # NO rank (Newmark's published rank is over 19-point index.total; we can't reproduce).
```

**Top-level API:**

```python
def project_newmark_2017(cells: dict, state: str) -> Newmark2017Score: ...

def load_newmark_2017_reference(repo_root: Path) -> dict[str, dict[str, int]]:
    """USPS → {sub_aggregate_id: int} reference from Phase 0-extracted Table 2 CSV.
    50 entries; each value carries `def.section_total`, `prohib.section_total` (informational),
    `disclosure.section_total`, `index.total` (informational)."""
```

**No aggregation function:** `project_newmark_2017_index_total` does **not** exist. Test for its absence. Constructing one would imply we can reproduce a value we cannot (prohib OOS).

**`unable_to_evaluate` convention** (per Sub-0 gap audit Pattern 3):

- Required input cells missing from `cells[row_id]` → helper returns the sentinel literal `"unable_to_evaluate"`.
- Top-level `project_newmark_2017` threads sentinels through `per_item_scores` as the string literal.
- Sub-aggregate totals are computed over **only the integer-valued** items: an `unable_to_evaluate` item is excluded from `def_section_total_partial` or `disclosure_section_total_partial` (NOT zeroed).
- Tests must cover the missing-cell case for every helper.

## Edge cases (document in module + tests)

Projection does NOT special-case — reads the cells normally; a counterfactual cell value of FALSE produces a projection of 0.
