- **Target:** `lobbyist_spending_report_filing_cadence`, the EnumCell wide-pass-failure row per iter 1+2's handoff. Pre-flight surfaced two structural complications: (1) row is split-axis (`enum (legal) + typed int 0-100 step 25 (practical)`); CPI's only indicator touching it is **IND_202** (not IND_201 as handoff said — that was a mis-label), and IND_202 scores ONLY the practical axis. Dispatcher only extracts legal axis. So wide-pass YAML's prompt was structurally wrong-axis (practical-axis IND_202 source quote populating a legal-axis EnumCell cell). (2) **No CPI legal-axis oracle exists for this row** — the statute is the oracle. WI §13.68(1) puts the filing duty on the principal; §13.68(4) routes lobbyist info through the principal → expected legal-axis enum = `'none'` (lobbyists do not file separately in WI). Vintage check §13.68(1)/(4) identical 2015 → 2025 (just "board" → "commission" rename).

- **Iter 3 (vocab-strip + EnumCell-aligned legal-axis prompt):** Replaced YAML prompt with "Under state law, how often must a LOBBYIST file a separate spending report? Answer with one of: 'annual', 'semiannual', 'quarterly', 'monthly', 'biennial', 'triannual', 'other', or 'none'. Use 'none' if lobbyists are not required to file a separate spending report (e.g., if statutory filing duties are assigned only to the principal/employer, with lobbyists providing information to the principal). If 'other', describe the actual cadence in the justification field." Dispatched single chunk via `--chunks lobbyist_spending_report` (~$0.74 — chunk has 30 legal cells vs `renewal_cadence`'s 8; per-cell cost ~$0.025 per model per run). **6/6 converged on `value: 'none'` at confidence=high.** All 6 cite both §13.68(1) AND §13.68(4) (wide-pass baseline cited §13.68(1) only). ### 2026-06-04 (evening, immediately after kickoff) — Iters 1 + 2 converged 6/6 on CPI MODERATE; ablation surfaces additive Phase A pattern
Convo: [`convos/20260604_phase_b_iter_1_and_2.md`](convos/20260604_phase_b_iter_1_and_2.md) · Iterations log: [`results/20260604_renewal_cadence_iterations.md`](results/20260604_renewal_cadence_iterations.md)

- **Iter 1 (vocab-strip + explicit units):** edited `compendium/source_quotes.yaml` prompt to "How often must a lobbyist renew their registration under state law? Answer in months as an integer (e.g., 12 for annual, 24 for biennial, 36 for triennial). If no renewal is required, return null." Dispatched single chunk via `--chunks registration_mechanics_and_exemptions` (~$0.29/iter using the new flag; vs ~$2.50 for full-6-chunk re-dispatch). **6/6 converged on `value: 24`** matching CPI MODERATE oracle exactly. Cost $0.2931.
- **Iter 2 (ablation: keep CPI vocab, append units):** restored CPI's verbatim YES/MODERATE/NO text in front + kept the units instruction at the end. **6/6 ALSO converged on `value: 24`.** Cost $0.2891. Cumulative $0.5822.
- **Load-bearing finding:** the cell-type-aligned units instruction is the load-bearing fix; CPI's YES/MODERATE/NO vocab is **harmless** when paired with that instruction. Both prompt directions converge identically. This means **Phase A pre-flight YAML audit's pattern is ADDITIVE, not destructive** — append a cell-type-aligned instruction to every prompt with tier vocabulary against a typed cell. Don't strip the rubric scoring language (preserves provenance, doesn't sacrifice convergence). Substantially smaller Phase A scope than the wide-pass Commit 3 convo anticipated.
- **Other observations:** Claude's iter-2 justifications cite both §13.63(1)(a) AND §13.64(2) (iter 1 only cited §13.63); GPT stays with just §13.63 across both iters. Same value, slightly richer justifications in iter 2. Production YAML now holds iter 2's prompt (recommended Phase A pattern).

Other 3 wide-pass-failure rows use EnumCell, DecimalCell-non-negative, BinaryCell — each ~$0.30 to test; ~$0.90 total to confirm generalization across cell types. Also: did NOT check the OTHER 17 CPI-readable rows for silent unit-mismatch issues (the GPT-emits-`2`-instead-of-`24` pattern that passes instantiation but is semantically wrong — wide-pass Commit 3 audit wouldn't have caught these).
- **Per-iteration cost ~$0.29, not $0.05-0.10 as plan estimated.** registration_mechanics_and_exemptions has 8 legal cells, so dispatch cost scales linearly with chunk size. At ~$0.29/iter, $5 budget supports ~17 iterations. Per-cell cost ~$0.03-0.04 per model per run.
