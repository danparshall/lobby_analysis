# HG 2007 (Hired Guns) Projection Implementation Plan

**Goal:** Ship `project_hired_guns_2007_disclosure_side(state, cells)` — a per-state projection function that reads 38 in-scope HG 2007 atomic items off v2 compendium cells and produces HG's 6 disclosure-side sub-aggregate scores (`def`, `ind_reg`, `ind_spending`, `emp_spending`, `e_filing`, `pub_access`) plus the `disclosure_partial` total, validated against per-state ground truth from CPI's 2007 scorecard if retrievable (Path A) or against per-state published totals via weak inequality if not (Path B).

**Originating conversation:** [`../convos/20260518_focal_hg_plans_drafting.md`](../convos/20260518_focal_hg_plans_drafting.md) (Sub-3 of Phase C — FOCAL plan-set + HG plan with retrieval gate). Builds on the Sub-0 playbook gap audit ([`../convos/20260514_rubric_plans_drafting.md`](../convos/20260514_rubric_plans_drafting.md), [`../results/20260514_playbook_gap_audit.md`](../results/20260514_playbook_gap_audit.md)) and on Sub-1's / Sub-2's plan-drafting conventions (Sunlight 2015 + Newmark 2017/2005 plans).

**Spec doc:** [`../../../historical/compendium-source-extracts/results/projections/hiredguns_2007_projection_mapping.md`](../../../historical/compendium-source-extracts/results/projections/hiredguns_2007_projection_mapping.md). The plan below is **derivative** — read the spec end-to-end for source quotes, cross-rubric annotations, and Open-Issue resolutions.

**Context:** Rubric #7 in Phase C's locked rubric order (after CPI 2015 C11, PRI 2010, Sunlight 2015, Newmark 2017, Newmark 2005, Opheim 1991). HG is the **largest contributing rubric** by item count (48 atomic items total; 38 in scope after dropping 10 enforcement + cooling-off items per the disclosure-only Phase B qualifier) and introduces the most NEW compendium rows of any single mapping (22 of 38 rows touched are HG-distinctive). It is **CPI 2015 C11's direct predecessor** — CPI's 14-item SII C11 sub-category compresses HG's 48-item scorecard, so the cross-rubric overlap with CPI is the largest in the contributing set.

**Confidence:** Medium-high. The 38 in-scope items map cleanly to 38 distinct v2 compendium rows; Phase 0 cross-check confirmed all expected rows exist in v2 under the renamed names (9 renames surfaced; see table below). Per-item scoring rules are paper-explicit per `CPI_2007__hired_guns_methodology.txt`. **The load-bearing uncertainty is per-state ground-truth retrieval** — CPI's per-state per-question scorecard was historically hosted at publicintegrity.org/politics/state-politics/influence/hired-guns/ but current availability is unverified. Plan specifies dual validation paths conditional on retrieval outcome.

**Architecture:** Declarative `_ATOMIC_SPEC` table dispatcher mirroring `src/lobby_analysis/projections/pri_2010.py`'s pattern, with **named helpers** for the 9 non-pure-passthrough items:

- Q2 (5-tier threshold magnitude); Q4 (5-tier deadline days); Q7 (5-tier amendment-deadline); Q15 (5-tier itemization threshold conditional)
- Q5 / Q20 (3-tier subject-or-bill on reg-form / spending-report sides — α form-type split)
- Q12 (4-tier derived from cadence binaries + session-calendar metadata)
- Q31 / Q32 (4-tier highest-applies access ladder; 4 binary cells per side)
- Q23 / Q24 (partial-scope projection — 1 pt of 3 / 2 respectively reachable from disclosure cells alone)
- Q16-Q19 (conditional on Q15 — itemization-detail cells; cascade)

Items Q1, Q3, Q6, Q8-Q11, Q13-Q14, Q21-Q22, Q25-Q30, Q33-Q38 (about 23 items) are pure binary or single-cell ordinal reads handled directly by the spec table.

**Branch:** `phase-c-projection-tdd` (worktree at `.worktrees/phase-c-projection-tdd`).

**Tech Stack:** Python 3.12, Pydantic v2, pytest, `uv` for env management. `load_v2_compendium()` from `lobby_analysis.compendium_loader` for cell access. `STATE_NAME_TO_USPS` from `scoring.calibration`.

## Validation regime — Dual-path (Strong if retrieval succeeds; Weak-inequality if not)

**HG ground-truth retrieval is gated.** Sub-0 identified two retrieval blockers:

1. **CPI's per-state per-question scorecard** (the 1,900-cell ground truth for 50 states × 38 in-scope items) was historically hosted at publicintegrity.org. Current availability is unverified. **Retrieval is a separate task — NOT a Track A sub-task** despite the playbook misattribution; Track A handles OH multi-vintage statute retrieval, not HG scorecard retrieval. The HG implementing agent (or a pre-launch agent) must attempt retrieval first and report success/failure.
2. **OH statute extraction** (Track A `oh-statute-retrieval`) for the OH-specific HG sub-task only. This affects per-state validation for OH (one of 50 states), not the broader 50-state validation.

### Path A — Strong (per-state per-item ground truth retrievable)

- Ground truth: 50 states × 38 in-scope items = **1,900 per-cell ground-truth values**, second-largest in the contributing-rubric set (after PRI 2010's 50 × 83 = 4,150 cells).
- Plus sub-aggregate totals: 50 × 6 sub-aggregates = 300 cells (if the scorecard publishes sub-aggregates; the methodology doc is unclear).
- Plus per-state overall total: 50 × 1 = 50 cells.

**Validation tests in Path A:**

- `project(cells)["def.section_total"] == reference[state]["def.section_total"]` for all 50 states (`==` exact match).
- Same for `ind_reg`, `ind_spending`, `emp_spending`, `e_filing`, `pub_access`.
- `project(cells)["disclosure_partial"] == sum of 6 sub-aggregates`.
- Per-item helper tests parameterized over every (state, item) cell against truth.
- **Tolerance** on Q23 + Q24 partial-scope reads: documented under-scoring up to 3 pts per state (1 + 2). Validation tests compare projected per-item value to "expected partial reading" (1 if cell TRUE, 0 if FALSE) rather than to HG's full 0-3 / 0-2 published value. Module's docstring reproduces the partial-scope rationale and Phase C tolerance.

### Path B — Weak-inequality (only per-state published total available)

If the per-state per-question scorecard is **not** retrievable, the only HG ground truth available is the per-state composite total (0-100). Path B validation:

- `project(cells)["disclosure_partial"] ≤ published_total[state] - 17_max_enforcement_revolving_door` for all 50 states. Equivalent to `our_partial ≤ published_total - 17`. The 17 is the maximum possible contribution from the 10 excluded items per the per-category maxima.
- **Per-item validation:** falls back entirely to cross-rubric overlap (which 22 of 38 in-scope items already cover via existing v2 rows + Phase C modules CPI/PRI/Sunlight/Newmark).
- **No per-sub-aggregate validation.**

**Path-selection logic in the test file:** environment variable `HG_GROUND_TRUTH_PATH` (defaults to "B"). If "A", load the per-state per-item CSV; if "B", load the per-state composite-total CSV. Tests parameterize accordingly.

### Cross-rubric overlap (independent of path)

22 of 38 in-scope items reuse pre-existing v2 rows. **Per-item cross-rubric agreement tests against the already-shipped modules** validate the OLD-row projections without needing HG's own scorecard:

- vs CPI 2015 C11: Q1/Q2/Q4/Q6/Q11/Q12/Q14/Q15 (gateway + threshold + cadence + spending-report core)
- vs Sunlight 2015: Q5/Q20 (α form-type split), Q11/Q13/Q14/Q15 (spending-report)
- vs PRI 2010: Q26/Q27 (principal-side)
- vs Newmark 2017/2005: Q14 (categorized expenses), Q23 (gifts disclosure binary)

A `tests/projections/test_cross_rubric_overlap.py` extension is the natural place to land these (NOT in `test_hg_2007_*`).

### Conditional cascades (Q16-Q19 on Q15)

Q16-Q19 only score if Q15's gateway is TRUE — i.e., if the state requires itemization at all. Implementation:

```python
def _project_q16_through_q19(cells, item_id):
    if not bool(cells.get("lobbyist_spending_report_includes_itemized_expenses", {}).get("legal_availability")):
        return 0  # Q15 gateway closed; itemized-detail cells don't score
    row_id = _Q16_19_ROW[item_id]  # one of the 4 detail rows
    return 1 if bool(cells.get(row_id, {}).get("legal_availability")) else 0
```

**Module test:** parameterize each of Q16-Q19 over (`itemized_gateway` ∈ {TRUE, FALSE}) × (`detail_cell` ∈ {TRUE, FALSE}). 4 cases × 4 items = 16 truth-table cells.

### Highest-applies tiers (Q31, Q32)

Q31 (directory) and Q32 (spending-report access) each read 4 binary cells encoding access tiers. HG's rule: take the highest-applies. Implementation:

```python
def _project_q31_or_q32(cells, side):  # side ∈ {"directory", "spending_report"}
    rows = _Q31_Q32_ROWS[side]  # 4 row ids, ordered photocopies→pdf→searchable→downloadable
    points = [4, 3, 2, 1]  # parallel to rows reversed (downloadable first → 4 pts)
    for row, pt in zip(reversed(rows), [4, 3, 2, 1]):
        if bool(cells.get(row, {}).get("practical_availability")):
            return pt
    return 0
```

**Module test:** parameterize over 2^4 = 16 combinations per side; 32 truth-table cells total.

### Partial-scope projection (Q23, Q24)

Q23 + Q24's "prohibited" tiers are OUT (3 pts and 2 pts respectively); only the "disclosed → 1 pt" tier is reachable from disclosure cells. Tests must compare against the *partial-scope expected value* (0 or 1), NOT against HG's published 0/1/2 (Q24) or 0/1/2/3 (Q23) values. Per-item validation:

```python
# Q23 test (Path A retrieval available):
assert project_q23(cells) == min(reference[state]["Q23"], 1)
# Q24 test (Path A retrieval available):
assert project_q24(cells) == min(reference[state]["Q24"], 1)
```

The "expected partial reading" is `min(published, 1)` — collapses the prohibition tier (2 or 3) to "disclosed" (1) for projection comparison. **Module docstring documents the -2 / -3 systematic under-scoring** so reviewers don't mistake it for a bug.

### Q12 derived projection from PRI cadence binaries

Q12 ("filings per 2-year cycle") reads HG's 4-tier ordinal off the 6 PRI cadence binaries (`lobbyist_spending_report_cadence_includes_{monthly,quarterly,triannual,semiannual,annual,other}`) plus session-calendar metadata (Open Q-3 below). Provisional implementation:

```python
_CADENCE_TO_2YR_FILINGS = {
    "monthly": 24,        # year-round monthly
    "quarterly": 8,
    "triannual": 6,
    "semiannual": 4,
    "annual": 2,
}

def _project_q12(cells):
    max_filings = 0
    for cad, n_per_2yr in _CADENCE_TO_2YR_FILINGS.items():
        if bool(cells.get(f"lobbyist_spending_report_cadence_includes_{cad}", {}).get("legal_availability")):
            max_filings = max(max_filings, n_per_2yr)
    # Note: "monthly during session" requires session-calendar metadata to disambiguate from monthly-year-round.
    # YAGNI Phase C: treat monthly as year-round (24/2yr); flag any state where Q12 projects 3pts but published says <3.
    if max_filings >= 10:
        return 3
    if max_filings >= 7:
        return 2
    if max_filings >= 4:
        return 1
    return 0
```

**Limitation:** the "monthly during session" case (e.g., a 4-month session state with monthly-during-session filing → 8 filings, not 24) cannot be disambiguated from the 6 cadence binaries alone. **Phase C accepts the projection over-counting on these states**; flag any divergence between projected and published Q12 in the validation output. Track this in Open Q-3.

## Standard module structure

```
src/lobby_analysis/projections/hg_2007.py
tests/projections/test_hg_2007_per_item.py        # per-atomic-item tests (path-aware)
tests/projections/test_hg_2007_ground_truth.py    # ground-truth loader tests (both paths)
tests/projections/test_hg_2007_aggregation.py     # aggregation + path-A or path-B end-to-end + rank
```

Module shape (mirror PRI 2010 for the declarative table; named helpers for the 9 non-passthrough items):

- Module docstring naming spec doc + ground-truth paths + dual-validation-path explanation.
- Constants: `_ATOMIC_ITEMS` (Q1..Q38, 38 ids); `_OOS_ITEMS: frozenset[str] = frozenset({"Q39", ..., "Q48"})`; `_LEGAL = "legal_availability"`, `_PRACTICAL = "practical_availability"`.
- Score model (Pydantic `BaseModel`, frozen): `HiredGuns2007Score` with `state`, `atomic_scores: dict[str, int]`, 6 sub-aggregate fields (`def_section_total`, `ind_reg_section_total`, etc.), `disclosure_partial`. **No `index_total`** (would smuggle a wrong-by-design API).
- Per-item layer: declarative `_ATOMIC_SPEC: dict[str, tuple[str, str, Callable]]` table for the 23 passthrough items + 9 named helpers for the special-shape items.
- Aggregation: pure sum within each sub-aggregate. No paper-derived rollup helper needed (HG's published rule is a raw sum).
- Top-level: `project_hired_guns_2007_disclosure_side(cells, state)` returns `HiredGuns2007Score`.
- Ranking: `rank_hg_2007_states(scores)` with **competition (1224) ranking** per playbook default. Tie-break: higher `disclosure_partial` first; secondary on `def_section_total`.
- Ground-truth loaders: `load_hg_2007_per_item_reference(repo_root)` (Path A — returns 50-state × 38-item dict-of-dicts if scorecard CSV exists, else raises `FileNotFoundError`) and `load_hg_2007_per_state_total_reference(repo_root)` (Path B — returns 50-state × 1-total dict).

## Test structure

Per the test-driven-development skill: write all tests first, watch them fail, write minimal code to pass.

### Per-item tests (`test_hg_2007_per_item.py`)

- Parameterize each of the 23 passthrough items over `{TRUE, FALSE}` cell value → expected 0 or N points.
- Q5 / Q20 (3-tier categorical): parameterize over `{(general=T, bill=T), (general=T, bill=F), (general=F, bill=T), (general=F, bill=F)}` → expected {3, 1, 3, 0}. 8 cases (4 per side × 2 sides).
- Q2 / Q4 / Q7 / Q15 / Q33 (typed ordinals): parameterize over each tier boundary + null + extreme values.
- Q12 derived: parameterize over each cadence binary set + multi-cadence-TRUE cases (max-applies semantics).
- Q16-Q19 conditional: 4 truth-table cases × 4 items = 16 cells (per "Conditional cascades" above).
- Q31 / Q32 highest-applies: 2^4 = 16 cases per side = 32 cells.
- Q23 / Q24 partial-scope: 2 cases each (cell TRUE → 1; cell FALSE → 0).
- Q38 4-tier cadence: parameterize over `{daily, weekly, monthly, semiannual_or_less_often, null}`.

**Estimated total per-item test cells:** 23 × 2 + 8 + 5 + 6 + 16 + 32 + 4 + 5 ≈ **120 per-item truth-table cells.**

### Ground-truth loader tests (`test_hg_2007_ground_truth.py`)
