# 2026-06-09 — Justia 2025 expansion to all 50 states (Plan)

**Branch:** `api-multi-vintage-retrieval` (worktree `.worktrees/api-vintage`)
**Convo of origin:** [`../convos/20260609_2025_50_state_expansion.md`](../convos/20260609_2025_50_state_expansion.md) (written at finish-convo)
**Machine:** Dans-MacBook-Pro (CF-clear so far this session, per 5-27 + 6-05 precedent)

## Goal

Take the Justia 2025 statute corpus from **16 → 50 states** by dispatching Method B subagent canaries for the 34 missing states and consuming the resulting `proposed_urls` into `data/statutes/<STATE>/2025/sections/*.txt`.

## Scope decisions (locked via AskUserQuestion this session)

| Decision | Choice | Reasoning |
|---|---|---|
| Vintage | **2025 only** | No published rubric oracle is at 2025; this is for the data layer, not validation. CPI 2015 / PRI 2010 oracles already covered by the priority-10 work. |
| Pacing | **Canary 3 (1 easy + 2 tricky), then fan out 31** | Protects against branch-state drift in the dispatch template + new long-tail failure modes. ~$0.30 risk before commit. |
| Spend ceiling | **$5** | Expected ~$3.40 (34 subagents × ~$0.10) + ~$1.60 buffer. |
| Sequencing vs `cross-state-cpi-2015-validation` trends | **Parallel — don't wait** | Statute corpus is useful for many things besides v2.2 schema design. |
| README target | **New `docs/active/api-multi-vintage-retrieval/README.md`** + one-line pointer in repo root README "Pull pipelines" | Branch-scoped infra doc; high-level pitch stays clean. |

## Phasing

### Phase 1 — Canary (3 states, ~$0.30, 5-10 min)

Dispatch 3 Method B subagents per [`plans/_handoffs/20260519_subagent_dispatch_prompt.md`](_handoffs/20260519_subagent_dispatch_prompt.md), one batch concurrent:

| State | Regime prior | Why canary |
|---|---|---|
| **AL** | Standard bicameral; Ethics Code Title 36 §25-1-1 et seq. | Clean test the template still runs as-is; alphabetical-first; no prior canary in this branch. |
| **LA** | Parallel civil-code / revised-statutes structure (RS 24:50 et seq. + RS 49:71 et seq.) | Tests whether Method B handles a state with **two parallel codes** — the pass-1 prompt must pick correctly between Civil Code and Revised Statutes. Closest analog to OH's 3-body regime, but with a structural twist. |
| **NE** | Unicameral; Accountability and Disclosure Act §49-1480 et seq. | Tests whether unicameral codification breaks any pass-1/pass-2 assumptions about "Legislative" vs "Senate"/"House" title naming. Zero prior exposure. |

Acceptance gates before fan-out:
- All 3 `result.json` files written with `playwright_errors: []`.
- `proposed_urls` count ≥ 4 for each (avoids the "TOC-page-mistaken-for-section" failure mode the CO 2025 bug surfaced).
- No CF blocks at pass-1.
- For each: spot-check at least one `proposed_urls` entry against the state's actual lobbying chapter (manual cross-check — for AL, expect §36-25-1.1 et seq.; for LA, expect RS 24:51-58 + RS 49:71-83; for NE, expect §49-1480 et seq.).

If **any** canary fails: stop, investigate, do not fan out.

### Phase 2 — Fan out (31 remaining states, ~$3.10, 60-90 min)

Remaining 31: AZ, CT, DE, GA, HI, ID, IN, IA, KS, KY, ME, MD, MN, MS, MO, MT, NV, NH, NJ, NM, ND, OK, OR, RI, SC, SD, TN, UT, VT, VA, WY.

Dispatch in **batches of 3 concurrent** per the 2026-05-18 CF-sustainability finding. ≈10-11 batches.

Per-batch protocol:
1. Pre-batch: re-check CF posture with a direct `subagent_fetch_save.py pass1` on one upcoming state (cheap probe, no API spend).
2. Dispatch 3 general-purpose subagents via Agent tool with the dispatch prompt.
3. Inspect each `result.json`: `proposed_urls` count, `playwright_errors`, `actual_vintage_used` (anything other than 2025 → flag for human review).
4. If batch CF-clean: continue. If 1+ blocks: pause, retry blocked state(s) next batch with different seed-text variation if available, else mark for follow-up session.

**Known awkward states to be alert for in fan-out:**
- **WY** — confirmed Justia hosts only 2010 (per current `data/statutes/WY/` inventory). Subagent will fall back via the `<VINTAGE>-1`, `<VINTAGE>-2` retry logic; expect `actual_vintage_used: 2010` and flag for human review.
- **DE** — lobbying ethics provisions may be split between Title 29 Ch. 58 (Public Officers) and Title 29 Ch. 91 (Public Integrity Commission).
- **MD** — Public Ethics Law in State Government Article §§15-101 et seq.; may not be under a "Lobby" title.
- **VA** — deep title hierarchy; prior 2015 lossy canary on file.
- **AZ, GA** — prior 2015 lossy canaries on file; useful priors for pass-1 seed text but URL conventions may have shifted for 2025.

### Phase 3 — Section-body fetch (one Python pass, $0 API)

Once all 34 `result.json` files are present, write `scripts/fetch_50state_2025_sections.py` (modeled on `scripts/fetch_gap_cells_sections.py`):

- Iterates over the 34 new bundles.
- For each: extracts `proposed_urls`, calls `retrieve_statute_bundle(client, state_abbr=S, vintage_year=2025, urls=urls, dest_dir=data/statutes/S/2025)`.
- PlaywrightClient with `rate_limit_seconds=2.5`.
- Size-sanity at the end: median section size + any <500B file flagged.

States where median <2KB → STOP the per-state fetch and inspect (CO 2025 TOC-page bug from 5-27).

## Risks and mitigations

| Risk | Mitigation |
|---|---|
| CF window closes mid-session | Pre-batch CF probe; if 1+ blocks per batch, pause and re-evaluate posture. |
| New long-tail failure mode (e.g., a state with a 4-deep title hierarchy that exhausts pass-3 depth) | Canary surfaces it before fan-out; if seen during fan-out, mark for follow-up session rather than burning subagent budget. |
| Vintage substitution silently uses 2024 / 2023 / etc. | `actual_vintage_used` field on `result.json`; any non-2025 value flagged in the Phase 2 batch inspection. |
| Cumulative spend exceeds $5 | Budget tracked by counting completed batches; pause at batch 12 (~$3.60) for re-evaluation. |
| Branch-state drift in dispatch template | Canary phase exercises template as-is before fan-out. |
